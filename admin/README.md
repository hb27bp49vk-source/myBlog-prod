# myBlog Admin

独立博客内容维护台。当前版本实现：

- 本地草稿和文章、短记、专题编辑
- Gist 同步账号新增、登录与七天信任本机
- PBKDF2-SHA256（210,000 次）派生密钥和 AES-GCM 加密
- 测试库 / 正式库发布目标选择
- 正式发布文字二次确认
- 服务端发布 API 接口预留

## 本地预览

需要通过 HTTP 服务打开，不能直接双击 HTML。可在项目根目录运行任意静态文件服务器，然后访问 `/admin/`。

## 数据边界

- Gist Token 仅用于 Gist，同步账号信息在浏览器中加密保存。
- 正式库与测试库 Token 不进入前端、不进入 Gist。
- 发布按钮只调用同源 `/api/publish`。服务未连接时只进行发布预演，不写仓库。
- 首次绑定新设备仍需 Gist ID 或恢复包；账号到 Gist ID 的跨设备映射需要服务端账户注册表。

## 发布服务

部署前必须实现 `PUBLISH_API.md` 中的同源接口、登录会话、限流和仓库白名单。不要把 GitHub Token 写入 `admin.js`、HTML、localStorage 或公开仓库。
